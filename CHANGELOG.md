# Changelog

## 3.0.0

### Безопасность
- Поисковые роботы по User-Agent больше не получают счётчики (`botBehavior: 'skip'`), поэтому подмена UA не помогает боту попасть в статистику.
- Вместо `cookie=true` используется подписанный токен с датой выдачи. Произвольное значение cookie не принимается.
- Проверки клика: `isTrusted`, минимальная задержка, нажатие на саму кнопку, движение мыши, клик не в центр (±1 px: браузер округляет координаты клика), кнопка-ловушка.
- Обнаружение `navigator.webdriver` и headless-браузеров.
- Удалён `checkInternal`: переход по внутренней ссылке без подтверждения больше не загружает счётчики.
- Обход окна для переходов из поисковиков выключен по умолчанию (`skipForSearchVisitors`).

### Исправлено
- По итогам код-ревью: с `cookieDomain` подтверждение действует на всех поддоменах (соль подписи берётся из домена cookie); кнопку можно нажать скринридером (NVDA, JAWS, VoiceOver); скрипты выполняются по порядку и между разными шаблонами и `counters`; некорректный `data-area` больше не отключает остальные счётчики; `show()` до `init()` не ломает `init()`; `theme.duration` числом — миллисекунды; в тёмной теме не остаются светлые рамка и тень; ловушка фокуса работает и при `autoFocus: false`, плашка `bottom` немодальная; после закрытия фокус возвращается на место; конструктор не зависает на большом коде.
- Окно повторно показывалось постоянным посетителям: срок токена теперь продлевается при визите, токен дублируется в `localStorage`, `cookieTime` проверяется (нечисловое значение давало сессионную cookie), добавлен `cookieDomain`.
- Проверка cookie по подстроке `document.cookie.includes(name)` заменена точным разбором.
- Удалён отладочный обработчик `ptz-click` с `console.log`.
- Правила поисковых рефереров принимали поддомены-подделки вида `yandex.ru.evil.com`.
- Если `init()` стоял выше шаблонов со счётчиками (например, в `header`-шаблоне CMS), у вернувшихся посетителей эти счётчики не загружались. Теперь скрипт ждёт `DOMContentLoaded`.

### Изменено
- Доступность и валидность: 0 ошибок в W3C HTML и CSS валидаторах (окно, сгенерированный код, конструктор), 0 нарушений axe-core по WCAG 2.2 AA; `aria-describedby`, поддержка режима высокой контрастности, контраст кнопки отказа и крестика доведён до норм WCAG; автотесты доступности.
- CSS без префиксов `-webkit-*` и устаревших свойств; `pointer-events: initial` вместо `auto` (W3C CSS Validator не знает `auto`).
- Мобильная раскладка — до 575.98 px, как в Bootstrap (было 532 px).
- Конструктор: вид и цвет кнопки «Только необходимые».
- Кнопка «Только необходимые» (`declineButton`, по умолчанию выключена): закрывает окно без загрузки счётчиков, отказ запоминается на `declineTime` (по умолчанию до закрытия вкладки). Метод `show()` — открыть окно снова, например по ссылке «Настройки cookie».
- Конструктор: логотип и фавикон Пиксель Тулс, галочка «Кнопка „Только необходимые“».
- `theme.breakpoints`: значения темы для разных размеров экрана (число — «до N px», строка — медиазапрос), пересчитываются на лету; работает и в `themeDark`.
- Модификатор `inline`: текст слева, кнопки справа, на узких экранах — в колонку. Пресет «Плашка: кнопка справа» в конструкторе.
- Тексты по умолчанию — как у обычной cookie-плашки: «Мы используем файлы cookie, чтобы сайт работал корректно…», кнопка «Принять».
- Конструктор: раздел «Мобильная версия» (брейкпоинт темы), галочка «Текст слева, кнопка справа».
- Тёмная тема: `colorScheme: 'light' | 'dark' | 'auto'` (`auto` — как в системе, переключается на лету), `themeDark` для своих цветов, метод `setColorScheme()` для переключателя темы на сайте.
- `autoFocus`: можно не забирать фокус при открытии окна.
- `theme.gutter` — отступ окна от краёв экрана; длинный текст кнопки и заголовка переносится и не выходит за окно на узких экранах; `theme.text.linkDecoration`, `linkColorHover`, `linkDecorationHover`.
- Конструктор: фокус больше не уходит из полей в предпросмотр, пример для формата HTML, переключатель темы, цвета тёмной темы, отступ от краёв, подчёркивание ссылок; пипетки необязательных цветов показывают реальный цвет.
- Онлайн-конструктор (https://ak-alz.github.io/pts-lazyload/): визуальная настройка окна с живым предпросмотром, вставка номера Метрики, GA4 или своего кода, готовый код для сайта, ссылка на настройки. Публикуется на GitHub Pages при пуше в `master`.
- `cookieName` по умолчанию — `pts-lazyload-verified`. `cookieName` и `salt` задавать не обязательно: минимальная установка — `new PtsLazyLoad().init()`.
- `intercept`: перехват нажатия кнопки, крестика, клика по затемнению и Escape. Обработчик `(ctx, next)` решает сам: `next()` — подтвердить, `ctx.dismiss()` — закрыть окно без подтверждения (событие `pts-lazyload:dismiss`, колбэк `onDismiss`), ничего — оставить окно. Вызывается только для действий, прошедших проверку на бота.
- `theme` с группами `dialog`, `overlay`, `title`, `text`, `actions`, `button`, `close` и `animation`: цвета, шрифты, отступы, размеры, скругления, тени, размытие фона, анимация появления (`slide-up`, `slide-down`, `zoom`, `fade`, `none` или свой `transform`). Всё работает через CSS-переменные, поэтому стилизация через CSS сохраняется.
- `modal.text` поддерживает абзацы, `modal.content` принимает элемент или `<template>` со страницы, `modal.closeIcon` — своя иконка крестика.
- Кольцо фокуса на кнопке скрыто до первого нажатия клавиши.
- Опции закрытия окна: `closeButton` (крестик, шаблон `close`), `closeOnOverlay`, `closeOnEscape`. Закрытие засчитывается как подтверждение и проходит те же проверки, что и нажатие кнопки; способ виден в `reason`: `close`, `overlay`, `escape`.
- Документация на русском и английском: подробное описание каждого параметра с примерами, инструкции для 1С-Битрикс, WordPress, Tilda, MODX, OpenCart, Laravel, Symfony и Google Tag Manager (`docs/cms.md`), ссылки на статьи и техподдержку.
- Unit-тесты (Vitest) и e2e-тесты (Playwright), CI на GitHub Actions с проверкой актуальности `build/`.
- Коды счётчиков можно вставлять в `<template data-pts-lazyload>` (селектор — `counterSelector`) без экранирования `</script>`, место вставки задаётся через `data-area`.
- Скрипты счётчиков выполняются в порядке, как при обычной загрузке страницы: внешний скрипт без `async` блокирует следующий код.
- Окно генерируется скриптом, разметку на страницу добавлять не нужно.
- Структуру окна можно переопределить шаблонами (`templates`) и классами (`classNames`), как в Choices. Атрибуты защиты и доступности и кнопку-ловушку библиотека ставит сама; при ошибке в шаблонах используется окно по умолчанию.
- Стили переписаны по БЭМ (блок `.pts-lazyload`, `build/pts.lazyload.css` вместо `welcome-pt.css`), тема настраивается через CSS-переменные и параметр `theme`; добавлены модификаторы `--dark` и `--bottom`.
- Доступность: `role="dialog"`, `aria-modal`, фокус на кнопке, подтверждение с клавиатуры, `prefers-reduced-motion`.
- Новые события `pts-lazyload:show|verified|reject|blocked` и колбэки. `ptz-click` сохранён.
- Проект собирается Vite: исходники в `src/` (ES-модули, SCSS), в `build/` лежат обычная и минифицированная версии JS и CSS (UMD, es2018).
- Стили переведены на SCSS, значения по умолчанию можно переопределить через `@use ... with (...)`.
- Конфигурация v2.1 (`cookie_name`, `modalText`, `ptsLazyLoad`) поддерживается с предупреждением в консоли.
